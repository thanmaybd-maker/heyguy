HeyGuy runs your own, already signed-in Antigravity CLI (agy). Sign-in happens inside agy; HeyGuy never sees or stores your Google credentials. No API key needed.

Each reply starts a full agy agent session, so it is slower than a direct API call (about 10-20 s in our check). Use a Gemini or Claude API key above for lower latency.

Voice input (push-to-talk) uses the Gemini key for speech-to-text — the free tier is enough. Get one at aistudio.google.com.
